# IRIS — Living Darkroom concept + Antigravity build pack

This is a design execution pack for redesigning an **existing** IRIS iris-photography website.

## Files

- `index.html` — runnable, offline, no-dependency interaction prototype (CSS photographic exposure + four concise chapters). Open in any modern browser. It is a **creative proof-of-concept**, not a full production site.
- `assets/iris-amber.webp` — original generated concept asset used by the prototype.
- `CREATIVE_SPEC.md` — exact art direction, responsive composition, interaction choreography, visual QA, and engineering decisions.
- `ASSETS.md` — detailed image-production specifications, prompt, QC and permission requirements.
- `ANTIGRAVITY_RUNBOOK.md` — paste-ready starter prompt and staged implementation gates for the existing Next.js project.
- `desktop-preview.png`, `mobile-preview.png` — prototype full-page screenshots rendered in Chromium.

## Instructions

1. Unzip pack into a folder Antigravity can read, preferably at repo root `creative-reference/` (do not overwrite existing files).
2. Open `index.html` locally to experience the visual concept. Move pointer over the hero, click `Reveal the unseen` to fully develop the image and scroll.
3. Paste the **Boot prompt** from `ANTIGRAVITY_RUNBOOK.md` into Antigravity. Point it at your actual repo and the pack.
4. Review Stage 1 screenshots before accepting further stages. Reject generic redesigns using the spec's acceptance rules.
5. Replace prototype demo image with actual licensed or permissioned iris imagery before commercial launch; configure the real WhatsApp number.

## Prototype limitations

- No 3D/WebGL in this baseline. The production build may upgrade to WebGL **only if image quality and interaction improve**.
- No authentic client imagery, product pricing, confirmed pop-up, or WhatsApp number.
- Frame is a conceptual mockup, not a photographed product.
- Browser QA was performed on self-contained HTML in Chromium at 1440×900 and 390×844: no horizontal overflow and the reveal button changed state; screenshot files included. This **does not** establish production cross-browser or mobile device testing.
